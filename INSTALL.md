# INSTALL.md — инструкция для агента, который ставит плагины ученику

Читайте целиком перед первым действием. Всё, что нужно, — терминал ученика и это репозиторий.

## 0. Проверьте обстановку (один раз)

1. **ОС и домашняя папка DSH.** macOS: `~/.dsh`. Windows: `%USERPROFILE%\.dsh`.
   Если переменная `DSH_HOME` задана, используется она.
2. **Профиль.** Нужен `profiles/desktop/package.json`. Нет файла — приложение ни разу не
   запускалось либо это другая сборка: скажите об этом ученику и остановитесь.
3. **Node.** Сначала `node --version`. Если Node нет, возьмите его из приложения:
   - macOS: `/Applications/DeepSeek Harness.app/Contents/Resources/runtime/bin/node`
   - Windows: `%LOCALAPPDATA%\Programs\DeepSeek Harness\resources\runtime\bin\node.exe`
     (если путь другой — найдите папку приложения: `where /r %LOCALAPPDATA%\Programs dsh.cmd`
     или `Get-ChildItem "$env:LOCALAPPDATA\Programs" -Filter "DeepSeek*"`).
   Дальше в инструкции `node` означает любой из этих путей.
4. **Версия приложения.** Подойдёт `0.2.1-rc.5` и новее. Более старую лучше обновить:
   плагины используют клиентские API этой ветки.

## 1. Скачайте репозиторий в постоянное место

Папку потом нельзя удалять или переносить: плагины подключаются ссылкой на неё.

```bash
# macOS / Linux
git clone https://github.com/ykurilov/dsh-plugins.git ~/.dsh/student-plugins
```

```powershell
# Windows PowerShell
git clone https://github.com/ykurilov/dsh-plugins.git "$env:USERPROFILE\.dsh\student-plugins"
```

Без git: скачайте ZIP (`…/archive/refs/heads/main.zip`) и распакуйте в ту же папку,
чтобы внутри лежали `install.mjs`, `plugins.json` и `plugins/`.

Все дальнейшие команды выполняются из этой папки.

## 2. Покажите меню и спросите ученика

```bash
node install.mjs --list
```

Задайте **один** вопрос: какие плагины поставить. Перечислите по одному пункту на плагин:
название, одно предложение о пользе, что для него нужно. Отдельно скажите, какие входят
в рекомендуемый набор (те, что помечены «по умолчанию»), и что можно выбрать все или любые.

Не начинайте установку, пока ученик не ответил. Если он выбрал `soniox-voice-input`,
сразу предупредите про ключ Soniox (раздел 5) — без ключа кнопка микрофона работать не будет.

## 3. Установите выбранное

```bash
node install.mjs --plugins=sidebar-balance,session-spend
```

Скрипт сам: находит профиль `desktop`, дописывает `link:`-зависимости и `dsh.profile.bundles`
в `package.json`, запускает `pnpm install` встроенным в приложение pnpm, проверяет, что пакеты
появились в `node_modules`, и делает резервную копию манифеста (`package.json.bak-…`).
При ошибке манифест откатывается сам.

Полезные варианты: `--all` (всё), `--dry-run` (показать, что изменится, ничего не записывая),
`--json` (машинный итог), `--profile=<имя>` (другой профиль), `--dsh-home=<путь>`
(нестандартная домашняя папка DSH).

Успех — строки «Готово» и отсутствие ошибок. Код возврата `0`.

## 4. Перезапустите приложение

Состав плагинов читается на старте, поэтому:

- закройте DeepSeek Harness полностью и откройте снова;
- если закрывать нельзя, обновите окно: `Cmd+R` (macOS) или `Ctrl+R` (Windows) — но часть
  изменений (например, новый бандл целиком) всё равно потребует перезапуска.

Скажите ученику, что делаете перезапуск, — это его компьютер и его окно.

## 5. Проверка (обязательно, по пунктам)

| Плагин | Что должно появиться |
|---|---|
| `sidebar-balance` | Внизу слева, над строкой аккаунта, строка с балансом (`¥…` или `$…`) |
| `session-spend` | Под полем ввода, в полосе статистики, плашка «Потрачено ≈ $…» |
| `sidebar-brandless` | Логотип и надпись в верхней части сайдбара исчезли, «Новая сессия» выше |
| `panel-dom` | В новой сессии агент видит инструмент `sidebar_browser`; в панели «Браузер» открывается страница |
| `soniox-voice-input` | Микрофон в поле сообщения рядом с кнопкой отправки |

Проверять лучше глазами ученика или скриншотом окна (спросив разрешение). Для `panel-dom`
достаточно вызвать `sidebar_browser` с `action: "status"` — в ответе будет URL или сообщение об
отсутствии страницы, но не ошибка «плагин не найден».

Если после перезапуска чего-то нет — раздел 7.

## 6. Ключ Soniox (только если выбран голосовой ввод)

Ключ берётся из первого доступного места:

1. конфиг плагина `apiKeyFile` (в `cordis.patch.yml` профиля или в патче плагина);
2. переменная окружения `SONIOX_API_KEY`;
3. файл `~/.codex/secrets/soniox-api-key.txt` (Windows: `%USERPROFILE%\.codex\secrets\soniox-api-key.txt`).

Путь 3 — самый простой: попросите ученика положить туда ключ (одна строка, без кавычек).
Ключ — только в файл, не в переписку. После сохранения перезапустите приложение.

## 7. Если что-то пошло не так

- **«Не нашёл pnpm».** Скрипт не нашёл встроенный менеджер пакетов. Варианты: указать путь
  `--pnpm=<…>/runtime/primary-runtime/dependencies/pnpm/bin/pnpm.mjs` из папки приложения
  или поставить вручную CLI-командой приложения в каждом плагине:
  `dsh plugin --profile desktop add "link:<путь к папке плагина>"`.
- **«Не найден профиль».** Проверьте `--dsh-home`; на Windows это `%USERPROFILE%\.dsh`,
  на macOS `~/.dsh`. Профиль `desktop` появляется после первого запуска приложения.
- **Плагина нет в интерфейсе.** Проверьте, что его имя есть в `dsh.profile.bundles` профиля
  и что в `node_modules/<имя>` профиля лежит ссылка. Затем полностью перезапустите приложение.
- **Сломался запуск приложения.** Верните `package.json` из свежего `package.json.bak-…`
  рядом с ним и перезапустите.
- **`screenshot` в `panel-dom` не снимает.** На Windows используется PowerShell
  (`System.Drawing`); если он недоступен, снимок вернёт текст ошибки, остальные действия работают.
  Предложите `action: "snapshot"` вместо снимка.
- **Не трогайте** чужие профили, настройки моделей и другие плагины. Ставим только то,
  что выбрал ученик.

## 8. Удаление

```bash
node install.mjs --remove=panel-dom
```

Скрипт уберёт зависимости и записи из `bundles`, пересоберёт `node_modules` и уберёт ссылки.
Если плагины больше не нужны все:

```bash
node install.mjs --all --remove=sidebar-balance,session-spend,sidebar-brandless,panel-dom,soniox-voice-input
```

`--all --remove` не поддерживается намеренно: удаляйте по списку, чтобы видеть, что уходит.
