# Плагины DeepSeek Harness для учеников

```text
Ты устанавливаешь ученику подборку плагинов к DeepSeek Harness. Ниже всё, что нужно:
ссылка на репозиторий, состав подборки, порядок действий и правила. Работай по шагам.

РЕПОЗИТОРИЙ: https://github.com/ykurilov/dsh-plugins
Внутри: install.mjs (установщик), plugins.json (список плагинов с описаниями),
plugins/ (сами плагины), INSTALL.md (подробная инструкция), README.md.

ЧТО В ПОДБОРКЕ (id — что делает — что нужно для работы):
- locale-ru — русский язык интерфейса: меню, настройки, подписи — ничего.
- sidebar-balance — баланс аккаунта DeepSeek строкой в подвале сайдбара — вход в аккаунт DeepSeek.
- session-spend — примерный расход денег на текущую сессию под полем ввода — ничего.
- sidebar-brandless — убирает логотип из верха сайдбара, навигация поднимается выше — ничего.
- panel-dom — инструмент sidebar_browser: агент открывает страницы в панели «Браузер»,
  читает их и кликает — нужно десктопное приложение, не веб-версия в браузере.
- soniox-voice-input — кнопка микрофона в поле сообщения, распознавание речи —
  нужен ключ Soniox и разрешение на микрофон.
Первые пять — рекомендуемый набор. Голосовой ввод предлагай отдельно: без ключа он бесполезен.

ЧТО НУЖНО У УЧЕНИКА:
- DeepSeek Harness Desktop 0.2.1-rc.5 или новее, профиль desktop (создаётся при первом запуске).
- macOS 12+ или Windows 10/11.
- Node ставить не обязательно: если его нет в системе, возьми Node из самого приложения —
  macOS: /Applications/DeepSeek Harness.app/Contents/Resources/runtime/bin/node
  Windows: %LOCALAPPDATA%\Programs\DeepSeek Harness\resources\runtime\bin\node.exe
  Менеджер пакетов тоже берётся из приложения, отдельно ставить не нужно.

ПОРЯДОК ДЕЙСТВИЙ:
1. Скачай репозиторий в постоянную папку:
   macOS:   git clone https://github.com/ykurilov/dsh-plugins.git ~/.dsh/student-plugins
   Windows: git clone https://github.com/ykurilov/dsh-plugins.git "$env:USERPROFILE\.dsh\student-plugins"
   Без git — скачай архив https://github.com/ykurilov/dsh-plugins/archive/refs/heads/main.zip
   и распакуй туда же, чтобы внутри лежали install.mjs, plugins.json и plugins/.
   Папку потом нельзя удалять или переносить: плагины подключены ссылкой на неё.
2. Прочитай INSTALL.md целиком и дальше действуй по нему.
3. Выполни: node install.mjs --list
   и задай ученику ОДИН вопрос: какие плагины поставить. Покажи по строке на плагин:
   название — чем полезен — что нужно. Отметь рекомендуемый набор и скажи, что можно
   выбрать любые, все или ни одного.
4. Дождись ответа и поставь выбранное:
   node install.mjs --plugins=id1,id2
   id через запятую, из списка. Все сразу — node install.mjs --all.
   Установщик сам находит профиль ~/.dsh/profiles/desktop, дописывает зависимости и состав
   бандлов, ставит их встроенным в приложение пакетным менеджером и при ошибке возвращает
   package.json как было (резервная копия рядом: package.json.bak-…).
5. Перезапусти DeepSeek Harness — состав плагинов читается на старте. Спроси у ученика
   разрешение: это его компьютер. Если закрывать приложение нельзя, предложи обновить окно
   (Cmd+R на macOS, Ctrl+R на Windows), но часть изменений всё равно потребует перезапуска.
6. Проверь каждый установленный плагин по разделу «Проверка» из INSTALL.md.
7. Если выбран голосовой ввод — скажи, куда положить ключ Soniox, и не проси присылать его
   в чат. Ключ берётся из первого доступного места:
   конфиг плагина apiKeyFile; переменная окружения SONIOX_API_KEY;
   файл ~/.codex/secrets/soniox-api-key.txt
   (Windows: %USERPROFILE%\.codex\secrets\soniox-api-key.txt).
   Проще третье: одна строка в файле, без кавычек, затем перезапуск.
8. В конце дай короткий отчёт: что поставлено, что видно в интерфейсе, что не получилось
   и почему.

ЧТО ДОЛЖНО ПОЯВИТЬСЯ ПОСЛЕ УСТАНОВКИ:
- locale-ru — интерфейс на русском: меню, настройки, подписи.
- sidebar-balance — внизу слева, над строкой аккаунта, строка с балансом (¥… или $…).
- session-spend — под полем ввода, в полосе статистики, плашка «Потрачено ≈ $…».
- sidebar-brandless — логотипа и надписи в верху сайдбара нет, «Новая сессия» выше.
- panel-dom — в панели «Браузер» открывается страница, агент видит инструмент sidebar_browser.
- soniox-voice-input — микрофон в поле сообщения рядом с кнопкой отправки.

WINDOWS:
Всё работает так же, как на macOS, отличие одно: снимок панели в panel-dom на macOS делается
системным screencapture, а на Windows — через PowerShell (System.Drawing, с учётом масштаба
экрана). Если снимок не сработает, остальные действия sidebar_browser не затрагиваются —
используй action «snapshot» или «read» вместо снимка и скажи об этом ученику.

ЕСЛИ ЧТО-ТО ПОШЛО НЕ ТАК:
- Плагина нет в интерфейсе — полностью перезапусти приложение; если не помогло, проверь,
  что имя плагина есть в dsh.profile.bundles профиля и что в node_modules профиля лежит
  ссылка на папку репозитория.
- Приложение не запускается — верни package.json из свежего package.json.bak-… рядом с ним
  и перезапусти.
- Установщик не нашёл pnpm — укажи путь к менеджеру пакетов из приложения:
  --pnpm=<…>/runtime/primary-runtime/dependencies/pnpm/bin/pnpm.mjs
  либо поставь плагины через CLI приложения:
  dsh plugin --profile desktop add "link:<папка плагина>"
- Не найден профиль — проверь --dsh-home; на Windows это %USERPROFILE%\.dsh, на macOS ~/.dsh.

ПРАВИЛА:
- Не трогай чужие профили, модели, настройки и плагины, которых нет в этом репозитории.
- Ничего не удаляй без согласия ученика.
- Не выдумывай успех: если проверка не прошла — так и напиши и покажи текст ошибки.
- Папку ~/.dsh/student-plugins не удаляй и не переноси.

УДАЛЕНИЕ (если ученик попросит убрать плагины):
node install.mjs --remove=id1,id2
Команда убирает зависимости и записи из состава бандлов, пересобирает node_modules и удаляет
ссылки. После этого приложение нужно перезапустить.
```
