# Плагины DeepSeek Harness для учеников

Подборка плагинов к десктопному DeepSeek Harness: русский интерфейс, баланс аккаунта, расход сессии, сайдбар без логотипа, управление браузером в правой панели и голосовой ввод. Ставится в ваш профиль одной командой, ничего покупать и регистрировать не нужно.

Репозиторий: **https://github.com/ykurilov/dsh-plugins**

## Что в подборке

| Плагин | Что делает | Что нужно |
|---|---|---|
| `locale-ru` | Русский язык интерфейса: меню, настройки, подписи | — |
| `sidebar-balance` | Баланс аккаунта DeepSeek строкой в подвале сайдбара | вход в аккаунт DeepSeek |
| `session-spend` | Примерный расход денег на текущую сессию под полем ввода | — |
| `sidebar-brandless` | Убирает логотип из верха сайдбара, навигация поднимается выше | — |
| `panel-dom` | Инструмент `sidebar_browser`: агент открывает страницы в панели «Браузер», читает их и кликает | десктопное приложение, не веб-версия |
| `soniox-voice-input` | Кнопка микрофона в поле сообщения, распознавание речи | ключ Soniox, доступ к микрофону |

Пять первых — рекомендуемый набор. Голосовой ввод ставьте, только если есть ключ Soniox.

## Требования

- DeepSeek Harness Desktop `0.2.1-rc.5` или новее, профиль `desktop` (создаётся при первом запуске).
- macOS 12+ или Windows 10/11.
- Node ставить не обязательно: если его нет в системе, агент возьмёт Node и менеджер пакетов из самого приложения.

## Как поставить: промпт для агента

Скопируйте целиком и отправьте своему агенту в DeepSeek Harness. Он спросит, какие плагины нужны, поставит их и проверит результат.

```text
Ты устанавливаешь мне подборку плагинов к DeepSeek Harness.
Репозиторий: https://github.com/ykurilov/dsh-plugins

Порядок:
1. Скачай репозиторий в постоянную папку:
     git clone https://github.com/ykurilov/dsh-plugins.git ~/.dsh/student-plugins
   Windows: git clone https://github.com/ykurilov/dsh-plugins.git "$env:USERPROFILE\.dsh\student-plugins"
   Без git — скачай ZIP https://github.com/ykurilov/dsh-plugins/archive/refs/heads/main.zip и распакуй туда же.
   Папку потом не удаляй: плагины подключены ссылкой на неё.
2. Прочитай INSTALL.md целиком и дальше действуй по нему.
3. Выполни: node install.mjs --list
   и задай мне ОДИН вопрос: какие плагины поставить. Покажи по строке на плагин:
   название — чем полезен — что нужно для работы (ключ, вход в аккаунт, десктопное приложение).
   Отметь рекомендуемый набор и скажи, что можно выбрать любые, все или ни одного.
4. Дождись моего ответа и поставь выбранное:
     node install.mjs --plugins=id1,id2
   (id через запятую, из списка).
5. Учти мою систему: на Windows проверь пути %USERPROFILE%\.dsh и предупреди, что снимок
   панели там идёт через PowerShell; на macOS — обычные пути. Node, если его нет, возьми
   из самого приложения (пути есть в INSTALL.md).
6. Перезапусти DeepSeek Harness (спроси у меня разрешение — это мой компьютер) и проверь
   каждый установленный плагин по разделу «Проверка» в INSTALL.md.
7. Если выбран голосовой ввод Soniox — скажи, куда положить ключ, и не проси присылать его в чат.
8. В конце дай короткий отчёт: что поставлено, что видно в интерфейсе, что не получилось и почему.

Правила:
— Не трогай другие профили, модели, настройки и плагины, которых нет в этом репозитории.
— Ничего не удаляй без моего согласия.
— Не выдумывай успех: если проверка не прошла — так и напиши, покажи текст ошибки.
— Если установка сорвалась, верни профиль в исходное состояние по резервной копии
  package.json.bak-… (INSTALL.md, раздел 7) и скажи, что именно помешало.
```

## Как поставить руками

Если удобнее без агента, из папки с репозиторием:

```bash
node install.mjs --list                                              # что есть
node install.mjs --plugins=locale-ru,sidebar-balance,session-spend    # поставить выбранное
node install.mjs --all                                               # всё
node install.mjs --remove=panel-dom                                  # убрать
```

Скрипт сам находит профиль `~/.dsh/profiles/desktop`, дописывает зависимости и состав бандлов, ставит их встроенным в приложение пакетным менеджером и при ошибке возвращает `package.json` как было. Резервная копия остаётся рядом: `package.json.bak-…`.

После установки приложение нужно полностью закрыть и открыть заново: состав плагинов читается на старте.

## Windows

Всё работает так же, как на macOS, исключение одно: снимок панели в `panel-dom` на macOS делается системным `screencapture`, а на Windows — через PowerShell (`System.Drawing`, с учётом масштаба экрана). Если снимок панели не сработает, остальные действия `sidebar_browser` не затрагиваются — попросите агента открыть `action: "snapshot"` или `read` вместо снимка.

## Голосовой ввод Soniox

Ключ берётся из первого доступного места:

1. конфиг плагина `apiKeyFile`;
2. переменная окружения `SONIOX_API_KEY`;
3. файл `~/.codex/secrets/soniox-api-key.txt` (Windows: `%USERPROFILE%\.codex\secrets\soniox-api-key.txt`).

Проще всего третье: положите ключ одной строкой в файл, без кавычек, и перезапустите приложение. Ключ не отправляйте в чат.

## Проверка после установки

| Плагин | Что должно появиться |
|---|---|
| `locale-ru` | Интерфейс на русском |
| `sidebar-balance` | Внизу слева, над строкой аккаунта, строка с балансом |
| `session-spend` | Под полем ввода плашка «Потрачено ≈ …» |
| `sidebar-brandless` | Логотипа и надписи в верху сайдбара нет |
| `panel-dom` | В панели «Браузер» открывается страница, агент видит инструмент `sidebar_browser` |
| `soniox-voice-input` | Микрофон рядом с кнопкой отправки |

## Если что-то пошло не так

- **Плагина нет в интерфейсе.** Полностью перезапустите приложение. Если не помогло — проверьте, что имя плагина есть в `dsh.profile.bundles` профиля и что в `node_modules` профиля лежит ссылка на папку репозитория.
- **Приложение не запускается.** Верните `package.json` из свежего `package.json.bak-…` рядом с ним и перезапустите.
- **Агент пишет, что не нашёл pnpm.** Пусть укажет путь к менеджеру пакетов из приложения: `--pnpm=<…>/runtime/primary-runtime/dependencies/pnpm/bin/pnpm.mjs`, либо поставит плагины через CLI приложения: `dsh plugin --profile desktop add "link:<папка плагина>"`.
- **Папку репозитория нельзя удалять или переносить** — плагины подключены ссылкой на неё.

## Удаление

```bash
node install.mjs --remove=locale-ru,panel-dom
```

Команда убирает зависимости и записи из состава бандлов, пересобирает `node_modules` и удаляет ссылки. После этого перезапустите приложение.
