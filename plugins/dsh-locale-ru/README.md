# Русский язык для DeepSeek Harness

Клиентский плагин-пакет, который добавляет русский язык в интерфейс DSH.
Все строки интерфейса (боковая панель, чат, настройки, плагины, автозадачи,
траектория, диалоги подтверждений и т. д.) переведены в
`dictionaries.json` и встроены в `client.js`.

## Как устроено

- `client.js` — клиентская половина: регистрирует язык `ru` и словари для всех
  пространств имён интерфейса через `ctx.locale`.
- `index.js` — хостовая половина (пустая, нужна загрузчику).
- `cordis.patch.yml` — вставляет запись `locale-ru` в профиль.
- `locale/` — название и описание пакета для страницы плагинов.

Пакет подключён к профилю `desktop`:

- `~/.dsh/profiles/desktop/node_modules/@local/dsh-locale-ru` → ссылка на эту папку;
- в `~/.dsh/profiles/desktop/package.json` добавлена зависимость и bundle;
- в `~/.dsh/profiles/desktop/cordis.patch.yml` — выбор языка:
  `- id: locale` / `config: preference: ru`.

## Как переключить язык

Настройки → Общие → Язык. Доступны «Русский», English и 中文.

## Как обновить переводы

1. Исправьте строки в `dictionaries.json`.
2. Пересоберите `client.js` (объект словарей должен совпадать с
   `dictionaries.json`, см. шапку файла) и перезагрузите окно приложения
   (⌘R) — DSH подхватит изменения без перезапуска.

## Как отключить

Удалите `@local/dsh-locale-ru` из списка `dsh.profile.bundles` в
`package.json` профиля (или выберите другой язык в настройках).
Резервные копии исходных файлов профиля лежат в `backup/`.
